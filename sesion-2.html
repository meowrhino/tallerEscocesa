qué es el css

El HTML dice qué es cada cosa. El CSS dice cómo se ve. Nada más.

00:00el concepto

una lista de decisiones visuales

CSS son las siglas de Cascading Style Sheets: hojas de estilo en cascada. Tampoco es un lenguaje de programación. Es una lista de decisiones: los párrafos así de grandes, el fondo de este color, el menú en fila.

La palabra importante es cascada: las reglas se leen de arriba abajo y las de abajo pisan a las de arriba. Por eso el orden dentro del archivo importa, y por eso la media query del móvil va siempre al final.

el momento de hoy

Borra en directo la línea <link rel="stylesheet"> del head y recarga. La página se queda desnuda: todo el contenido sigue ahí, sin ninguna decisión visual encima.

Eso es exactamente la diferencia entre las dos cosas, y verlo vale más que diez minutos de explicación.

00:00

cómo se enchufa

Una sola línea en el <head> de cada página:

<link rel="stylesheet" href="estilo.css">

Un solo archivo estilo.css para toda la web. Cambias ahí el tamaño de letra y cambia en las cinco páginas a la vez. Ese es todo el truco.

selectores y la caja

Cómo se escribe una regla, a qué afecta, y el modelo de caja.

00:25

cómo se escribe una regla

body {
  background-color: #FBFAF7;
  font-size: 18px;
}

El selector (body) dice a qué afecta. Dentro van las propiedades y sus valores.

punto y coma al final de cada línea

Si te lo olvidas, esa línea deja de funcionar y a veces la siguiente también. Y no avisa nadie: no sale ningún error, simplemente no pasa nada.

00:25

a qué afecta cada selector

p { }                    todos los párrafos
header, main { }         los dos a la vez
nav a { }                los enlaces dentro de nav
a:hover { }              cuando el ratón está encima
article:last-child { }   solo el último de la serie
la confusión más común

La coma es «y también». El espacio es «dentro de». header, a son las cabeceras y todos los enlaces; header a son solo los enlaces de dentro de la cabecera. Son cosas muy distintas.

De dentro hacia fuera:

  • padding — relleno por dentro
  • border — la línea
  • margin — aire por fuera

tipografía

Qué letra, de qué tamaño, y a cuánta distancia una línea de otra.

01:00

las propiedades de la letra

font-family: "Iowan Old Style", Georgia, serif;
font-size: 18px;
font-weight: bold;
line-height: 1.6;
letter-spacing: 0.08em;
text-transform: uppercase;

En font-family pones varias separadas por comas: el navegador usa la primera que encuentre instalada. Por eso serif va al final, como comodín.

line-height de 1.5 a 1.6 para texto largo. Es el ajuste que más cambia la sensación de una web y el que más se olvida.

tipografías descargadas

Puedes descargar la tipografía y servirla desde tu carpeta en vez de llamar a Google Fonts en cada visita. Carga más rápido y no le cuentas a nadie quién visita tu web.

teoría · lo explico yo 01:40 · 20 minutos

color

Dos colores bien elegidos bastan. El tercero, solo para una cosa.

01:40

dos colores y un acento

body {
  background-color: #FBFAF7;
  color: #12233A;
}

a:hover {
  background-color: #F2E94E;
}

Un fondo, una tinta, y un acento que aparece poco. Con eso está montada casi cualquier web de artista.

Negro puro sobre blanco puro cansa la vista. Baja un poco los dos: un blanco con algo de calidez y un negro que en realidad sea azul muy oscuro.

contraste

Si el texto no se lee con el móvil al sol, no se lee. Gris claro sobre blanco es la manera más común de hacer una web bonita e ilegible.

Compruébalo en webaim.org/resources/contrastchecker: busca 4.5 o más para el texto normal.

composición

Ancho de columna, el menú en fila, y separar los bloques.

02:00

una columna que se lee

header, main, footer {
  max-width: 640px;
  margin: 0 auto;
}

max-width pone un tope al ancho. margin: 0 auto reparte el espacio sobrante a los dos lados por igual, así que centra el bloque.

por qué importa

Sin esto, en una pantalla ancha las líneas se hacen larguísimas y al saltar de renglón te pierdes. Entre 60 y 80 caracteres por línea es lo cómodo.

02:00

el menú en fila, y las imágenes

nav {
  display: flex;       pone los hijos en fila
  gap: 20px;            separación entre ellos
  flex-wrap: wrap;     que salten de línea si no caben
}

Y las imágenes, siempre, sin excepción:

img {
  max-width: 100%;
  height: auto;
  display: block;
}

Así una foto enorme nunca se sale de la pantalla, y no se deforma.

teoría · lo explico yo 02:20 · 15 minutos

que funcione en el móvil

Una sola media query, al final del archivo.

02:20

reglas solo para pantallas pequeñas

@media (max-width: 600px) {
  body { font-size: 17px; padding: 16px; }
  h1   { font-size: 27px; }
}

Lo de dentro solo se aplica si la pantalla mide 600px o menos. Y pisa a lo de arriba: por eso va siempre al final del archivo. Eso es la cascada.

compruébalo estrechando la ventana

Más directo que el modo dispositivo del inspector, y no hay que explicar nada. Arrastra el borde del navegador hasta que quede como un móvil.

Es donde se ve la web casi siempre. Si te falta tiempo hoy, salta la práctica libre pero no saltes esto.
