00:00apunte

vs code y github, separados a propósito

VS Code tiene un botón para conectarse a GitHub y subir cambios sin salir del programa. Hoy no lo usamos, y es una decisión.

Se aprende primero el camino largo —editar aquí, subir por la web— porque es el que deja ver qué está pasando: una carpeta tuya, y una copia en un servidor.

Cuando ese camino te aburra, que te aburrirá, el atajo está en el panel Control de código fuente de VS Code. Es un botón, no una terminal.

Pero para entonces ya sabrás qué hace, y si se rompe sabrás por qué.

una web es una carpeta

No hay nada más. Ni servidores misteriosos, ni una empresa detrás, ni una suscripción. Archivos de texto dentro de una carpeta.

mi-web/
├── index.html      ← la portada
├── proyectos.html
├── cv.html
├── estilo.css      ← el aspecto
└── img/
    ├── obra-1.jpg
    └── retrato.jpg

En cualquier web que te guste: botón derecho → Inspeccionar. Eso que sale es todo lo que hay.

Si mueves la carpeta entera, la web sigue funcionando. Si sacas un archivo de dentro, se rompe.

qué es el html

Antes de escribir una sola etiqueta: qué es esto y qué hace exactamente.

00:30el concepto

html no dibuja: estructura

HTML son las siglas de HyperText Markup Language. Lo importante es la palabra del medio: markup, marcado. No es un lenguaje de programación — no calcula, no decide, no tiene memoria.

Lo único que hace es marcar un texto diciendo qué es cada parte.

Texto sin marcar

Rita Mestre
Trabajo con cerámica y sonido.
Cámaras sordas
2026 · Gres

El navegador no sabe qué es cada línea. Lo pinta todo seguido, igual.

El mismo texto, marcado

<h1>Rita Mestre</h1>
<p>Trabajo con cerámica y sonido.</p>
<h3>Cámaras sordas</h3>
<p>2026 · Gres</p>

Ahora sí. Y con esa información puede jerarquizarlo, y un lector de pantalla puede leerlo con sentido.

la frase de hoy

El HTML dice qué es cada cosa. El CSS dice cómo se ve. Hoy solo hacemos lo primero: va a quedar feo, y está bien que quede feo.

00:30

tres cosas que hay que creerse

  1. La carpeta es la web. Si la mueves entera, sigue funcionando. Si sacas un archivo de dentro, se rompe.
  2. index.html es la portada. Ese nombre exacto: es el que busca el servidor cuando alguien entra sin pedir ninguna página concreta.
  3. img/obra.jpg significa «dentro de mi carpeta». Una imagen que esté en tu escritorio se ve en tu ordenador y en ningún otro sitio del mundo.
nombres de archivo

Sin espacios, sin acentos, sin ñ, sin mayúsculas. Foto Taller.JPG falla al publicar; foto-taller.jpg no.

Para un servidor, .jpg y .JPG son archivos distintos. En tu Mac funciona y al publicar deja de funcionar. Es el fallo número uno del taller.

00:30por qué separar

por qué el contenido va aparte del aspecto

Porque el contenido dura y el aspecto cambia. Dentro de cinco años querrás otra tipografía y otros colores, pero tu bio y tus proyectos serán los mismos.

Si están separados, rediseñas la web entera tocando un solo archivo. Lo verás en la sesión 2: el mismo HTML, cuatro webs.

Y porque hay lectores que no son ojos: buscadores, lectores de pantalla, el modo lectura del móvil. Todos leen la estructura.

Un <h1> escrito como <h1> es un título para todo el mundo. Un texto puesto grande a mano solo lo es para quien lo ve.

</article>
00:45el esqueleto

la estructura de una página

<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">                     acentos y ñ
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Rita Mestre</title>                la pestaña
  <link rel="stylesheet" href="estilo.css"> el aspecto
</head>
<body>
  <header> tu nombre y el menú </header>
  <main>   el contenido de esta página </main>
  <footer> contacto, créditos </footer>
</body>
</html>

head es lo que no se ve. body es lo que sí.

un solo h1 por página

h1 a h6 es jerarquía, no tamaño. El tamaño se decide luego, en el CSS. No uses un h4 porque quieras letra pequeña.

enlaces e imágenes

<a href="cv.html">CV</a>                      a otra página tuya
<a href="https://neocities.org">Neocities</a>  a otra web
<a href="mailto:rita@ejemplo.com">Escríbeme</a>  abre el correo

<img src="img/obra-1.jpg" alt="Cinco piezas de gres">
  • href es a dónde va. Para una web de fuera hace falta el https:// delante.
  • src es dónde está el archivo. img/ significa dentro de tu carpeta.
  • img no lleva etiqueta de cierre. Es de las pocas.
el alt no es opcional

Lo lee en voz alta un lector de pantalla y aparece si la imagen no carga. Descríbela como se la describirías por teléfono a alguien.

el fallo típico

Añadir el enlace nuevo solo en una de las dos páginas. Desde la otra no se llega, y parece que el enlace está mal cuando lo que falta es repetirlo.

<article>
  <h3>Cámaras sordas</h3>
  <p>2026 · Gres · Barcelona</p>
  <img src="img/obra-1.jpg" alt="…">
  <p>Dos líneas sobre el proyecto.</p>
</article>

Para el siguiente proyecto: copias el bloque entero, lo pegas debajo y cambias el texto. Así de aburrido. Así de fiable.

lo que esto no hace

formulario de contactoNecesita un servidor. Pon tu correo con mailto: — es lo que hace casi todo el mundo y no se rompe nunca.
tiendaPagos, stock y seguridad son otro proyecto. Enlaza a Bandcamp o Big Cartel.
blog automáticoCada entrada es un archivo que creas a mano. Para tres o cuatro al año, perfecto.
comentariosNecesitan base de datos y moderación. No.
reservasEnlaza a una herramienta externa.

Lo que sí hace: existir para siempre, cargar rápido, no costar nada al mes y no depender de ninguna empresa.

ejercicio 31 hora · en casa

deberes: reunir el material

No hay que programar nada. Es preparar el contenido, que es lo que más tarda y no se puede improvisar en clase. Sin esto, la sesión 2 no cunde.

Textos

  • Tu bio, escrita y revisada.
  • La ficha de cada proyecto: título, año, técnica, lugar, dos o tres líneas.
  • Tu CV: exposiciones, formación, lo que quieras incluir.

Referencias

  • Dos o tres webs que te gusten. Apunta qué te gusta de cada una.

Imágenes

  • Entre 5 y 10, en una carpeta.
  • Reducidas a 1600 píxeles de ancho, con Vista Previa, Paint o squoosh.app.
  • Sin espacios, sin acentos, en minúsculas: obra-2024.jpg, no Obra 2024.JPG.
ojo con el peso

Una foto de cámara pesa 8 MB y tarda una eternidad. Reducida son 300 KB y se ve igual en pantalla.

Si algo no funciona

  1. ¿Has guardado el archivo?
  2. ¿Has recargado? Forzada: Cmd+Shift+R o Ctrl+F5.
  3. ¿Falta cerrar una etiqueta o una comilla? VS Code lo marca en color.
  4. ¿Una imagen no sale? El nombre y el src tienen que coincidir exactamente.
